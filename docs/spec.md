# AFC 90 — 서비스 기획 명세 (Spec)

## 1. 핵심 기능

### A. 90일 도장깨기 (Daily Check-in)

**메인 캘린더**
- 90일 그리드 뷰 제공
- 하루 성공 시 스탬프(도장) 찍는 애니메이션 효과
- 오늘 날짜 강조, 미래 날짜 비활성화

**연속 달성 배지 (마일스톤)**

| 마일스톤 | 배지 이름 | 효과 |
|---------|----------|------|
| 3일 | 첫 고비 돌파 | 축하 팝업 |
| 7일 | 일주일 챔피언 | 특별 배지 + 이펙트 |
| 21일 | 습관의 씨앗 | 습관 형성 완료 알림 |
| 50일 | 절반의 영웅 | 애니메이션 + 공유 기능 |
| 90일 | AFC 완주자 | 풀 스크린 축하 이펙트 + 인증서 |

**SOS 버튼 (위기 극복)**
- 술자리·유혹 상황에서 접근 가능한 상시 노출 버튼
- 탭 시 즉각적 동기부여 문구 노출 (과학적 사실, 명언 등 랜덤 제공)
- 금주 지속 시 절약 중인 칼로리/비용 실시간 표시

---

### B. 타임라인별 신체 변화 시각화 (Body Tracker)

**인포그래픽 대시보드**
- 현재 금주 일차에 맞춰 신체 변화 자동 표시
- 트래킹 부위: 간, 뇌, 피부, 수면, 체중, 심혈관

**건강 지표 예측**
- 온보딩 시 입력: 키, 몸무게, 평소 주간 음주량(잔/주)
- 기반 예측 제공:
  - 90일 후 절약 칼로리 총량
  - 예상 체중 감량 (kg)
  - 절약 비용 (원)

**일차별 신체 변화 로드맵**

| 기간 | 신체 변화 |
|------|----------|
| 1~3일 | 체내 알코올 배출, 수면 패턴 일시 불안정 |
| 1주일 | REM 수면 정상화, 아침 피로도 감소, 피부 수분 증가 |
| 1개월 | 간 지방 최대 15% 감소, 혈압·콜레스테롤 안정화, 체중 감량 시작 |
| 3개월 | 적혈구 재생 완료, 도파민 수용체 정상화, 심혈관 위험 대폭 감소 |

---

### C. AI 기반 맞춤형 건강 코칭 (Health Coaching Agent)

**RAG 기반 지능형 코칭**
- 의학 저널 및 건강 문헌 기반 RAG 파이프라인 구축
- 할루시네이션 없는 정확한 건강 피드백
- 사용자 금주 일차·증상에 맞춘 개인화 응답

**데일리 미션**
- 금단 증상 주기에 맞는 미션 자동 생성
  - 피로: 낮잠 루틴, 피로 회복 음식 추천
  - 불면증: 수면 위생 가이드, 취침 루틴
  - 단맛 당김: 탄산수 활용법, 저당 대체 간식
- 가벼운 운동 추천 (5~10분 루틴)

## 2. 기술 스택

| 구분 | 기술 | 선택 이유 |
|------|------|----------|
| Frontend | React, Tailwind CSS | 컴포넌트 기반 개발, 모바일 최적화 반응형 UI |
| Backend | Node.js, Express | 비동기 처리, 프론트엔드와 유연한 REST API 통신 |
| DB | PostgreSQL | 사용자 데이터, 체크인 기록, 배지 정보 저장 |
| AI / Vector | Vector DB (pgvector 또는 Pinecone) | RAG 파이프라인용 벡터 임베딩 검색 |
| Infra | GCP Cloud Run 또는 AWS | 컨테이너 기반 배포, 오토 스케일링 |

---

## 3. 사용자 플로우

```
온보딩 (키/몸무게/음주량 입력)
    ↓
메인 대시보드
    ├── 오늘 체크인 (도장 찍기)
    ├── 신체 변화 인포그래픽 (현재 일차)
    └── 데일리 AI 미션 확인
    ↓
마일스톤 달성 시 → 배지 + 축하 이펙트
    ↓
SOS 버튼 (언제든 접근 가능)
    ↓
AI 코칭 채팅 (질문/답변)
```

## 4. 화면 목록

| 화면 | 설명 |
|------|------|
| 온보딩 | 기초 정보 입력 (키, 몸무게, 음주량) |
| 메인 대시보드 | 체크인 버튼, 현재 일차, 신체 변화 요약 |
| 90일 캘린더 | 그리드 뷰, 도장 현황, 배지 목록 |
| Body Tracker | 일차별 상세 신체 변화 인포그래픽 |
| AI 코칭 | 채팅 UI, 데일리 미션 |
| SOS 모달 | 위기 순간 동기부여 문구 노출 |
| 마이페이지 | 예측 지표, 설정, 배지 컬렉션 |

## 5. MVP 범위 (1차 출시 기준)

- 온보딩 + 기초 정보 입력
- 90일 캘린더 + 체크인 (도장 찍기)
- 마일스톤 배지 (3·7·21·50·90일)
- 일차별 신체 변화 인포그래픽 (정적 콘텐츠)
- SOS 버튼 + 동기부여 문구

**2차 출시 (MVP 이후)**
- AI 코칭 채팅 (RAG 파이프라인)
- 데일리 미션 자동 생성
- 건강 지표 예측 대시보드
- PWA (홈 화면 추가)
