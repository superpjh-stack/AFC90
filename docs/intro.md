# AFC 200 — 서비스 소개

## 서비스명

**AFC 200** (Alcohol Free Challenge 200)

## 한 줄 요약

200일 금주 챌린지를 통해 매일의 성취감을 기록하고, 내 몸의 변화를 눈으로 확인하는 모바일 웹 서비스.

## 목적

술을 끊고 싶지만 혼자서는 유지하기 어려운 사람들을 위해, 200일이라는 구체적인 기간 동안:

- **하루하루의 성취감**을 스탬프와 배지로 시각화하고
- **신체 회복 과정**을 과학적 데이터 기반으로 인포그래픽으로 안내하며
- **AI 건강 코칭**으로 개인 맞춤형 동기부여를 제공한다

90일(3개월)은 세포 수준의 재생이 완성되는 시점이지만, 금주 재발 위험이 가장 높은 구간의 한복판이기도 하다. AFC 200은 그 구간을 **완전히 통과하는 지점**까지 사용자를 데려간다.

## 플랫폼

모바일 최적화 웹 (Mobile Responsive Web)

별도 앱 설치 없이 브라우저에서 바로 접근 가능하며, PWA 전환을 통한 홈 화면 추가도 지원한다.

## 핵심 가치

| 가치 | 설명 |
|------|------|
| 시각적 성취감 | 게임화(Gamification)를 통한 도장깨기 방식으로 금주 지속성 향상 |
| 신체 변화 트래킹 | 금주 일차별 간·뇌·피부·체중·혈액·정신력 변화를 직관적 인포그래픽으로 안내 |
| 장기 완주 설계 | 8개의 마일스톤을 촘촘히 배치해 200일이라는 긴 여정에서도 동기가 끊기지 않도록 설계 |
| 지능형 건강 코칭 | RAG 기반 AI가 과학 문헌을 근거로 개인화된 조언 제공 |

## 타겟 사용자

- 금주를 결심했지만 혼자 유지하기 힘든 성인
- 음주로 인한 건강 악화를 인지하고 변화를 원하는 사람
- 30일·90일 챌린지를 해봤지만 끝난 뒤 다시 돌아간 경험이 있는 사람
- 200일(약 6.5개월)이라는 명확한 목표로 도전하고 싶은 사람
