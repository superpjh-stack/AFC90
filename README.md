# AFC 200

**Alcohol Free Challenge 200** — 200일 금주 챌린지 모바일 웹.

매일 도장을 찍어 금주 기록을 쌓고, 8종의 마일스톤 배지와 일차별 신체 변화 인포그래픽으로 200일 완주를 돕는다.

```bash
npm install
npm run dev
```

- 기획 문서: [`docs/intro.md`](docs/intro.md) · [`docs/problem.md`](docs/problem.md) · [`docs/spec.md`](docs/spec.md)
- 챌린지 기간·마일스톤 단일 출처: `src/data/challenge.js`
